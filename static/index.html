统计单位与区间

单次训练按连续时间块重采样，估计有效观测条件下的均速变化；分别比较 0.5、1、2 秒块长。视频帧不作为独立训练样本。

块间近似独立、运动分布相对稳定是区间估计的前提。短片、缺失与块长选择会影响结果；区间不包含定位系统误差。

空间模型与误差传播

区域信息熵 H = −Σ p log₂p 描述六区域位置分布，不是表现评分。标定实验假设四角坐标受到独立高斯扰动，固定原始检测，重新计算单应性映射。

每种扰动做 200 次模拟，最多均匀抽取 2,500 个位置。位移与区域变化反映假设下的敏感性，不是实测标定精度。

专项成功率

成功率来自人工记录的成功次数 / 尝试次数，区间使用 Wilson 方法并假设二项试验。同一回合内的相关尝试需在研究设计中处理。组间比较以训练记录为单位，不将每次尝试或视频帧重复计作独立训练。

组间比较与配对

每条录像选择一名球员。独立样本使用 Welch 均值差区间与 Cliff’s δ；配对设计使用配对 t 区间与 dz。差值方向统一为 B − A。

相同配对编号须对应一条 A 组与一条 B 组记录。请匹配球员、训练任务与拍摄条件；独立设计要求录像间独立，配对设计要求配对单元间独立。

公开示例与重复轨迹不计入组间样本。p 值为双侧且未作多重比较校正；观察性差异不能直接证明训练干预有效。

复现与导出

JSON 包含来源、运行编号、轨迹哈希、方法、参数与固定随机种子。CSV 导出计算指标；组间 CSV 同时保留逐条训练数据。
